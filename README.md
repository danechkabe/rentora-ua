# Філіп Апартмент

Адаптивний статичний сайт Філіп Апартмент для довгострокової оренди кімнат. Побудований без бекенду, секретів або платних API та готовий для **GitHub Pages**.

> Усі оголошення в репозиторії демонстраційні. Їхні ціни, адреси, координати, фото й відстані не є реальними даними. Замініть їх на перевірену інформацію перед публікацією.

## Можливості

- Головна сторінка з трьома картками кімнат у ряд, кольоровими статусами та контактами Філіпа.
- Картка кімнати показує тип вбиральні, поверх, вулицю та ціну.
- Карта показує одну точку на квартиру. Попап перегортає кімнати у правильному порядку: доступні, вільні з дати, зайняті.
- Hash URL для кімнат, наприклад `#/room/room-sun`, працюють після перезавантаження на GitHub Pages.
- Детальна сторінка містить: ціну, задаток, комунальні, договір, техніку, вбиральню, кількість кімнат, правила куріння й тварин, мапу, інші кімнати квартири та контакти Філіпа.
- Галерея, статуси доступності, умови, комунальні послуги, приблизні демонстраційні відстані, контактна кнопка.
- Leaflet + OpenStreetMap. На карті використовується один маркер на квартиру, тому кімнати не дублюються в одній точці. Атрибуція OpenStreetMap показується у контролі Leaflet та у футері.
- Стани завантаження даних, порожнього каталогу та помилки завантаження карти.

## Локальний запуск

Для `fetch()` JSON потрібен локальний HTTP-сервер, а не відкриття файлу подвійним кліком.

```bash
cd rentora-ua
python3 -m http.server 8000
```

Відкрийте [http://localhost:8000](http://localhost:8000). Для тесту прямого посилання відкрийте, а потім оновіть сторінку:

```text
http://localhost:8000/#/room/room-podil-sun
http://localhost:8000/#/apartment/apt-podilska-terrace
```

## Як редагувати оголошення

Усі дані зберігаються в [`data/listings.json`](data/listings.json):

- `apartments` містить квартири та поле `roomIds`.
- `rooms` містить кімнати та поле `apartmentId`, що привʼязує кімнату до квартири.
- Кожен обʼєкт має ідентифікатор, тип, назву, опис, ціну, район, демонстраційну адресу, координати, площу, фото, ванну, поверх, мешканців, комунальні послуги, місця поруч і статус.

### Додати фото

1. Додайте оптимізовані зображення, наприклад у `images/`.
2. Вкажіть відносний URL у масиві `photos`, наприклад `"images/listings/room-01.jpg"`.
3. Додайте зрозумілий текст до `title`, бо він використовується в альтернативному описі фото.

- Додайте справжнє фото Філіпа: в `site.contact.photo` вкажіть відносний шлях, наприклад `"images/philip.jpg"`, і змініть `photoAlt`. Поки поле порожнє, сайт чесно показує нейтральний ініціал замість чужого фото.

### Координати та приватність

`coordinates` має формат `[latitude, longitude]`. Не публікуйте точні координати приватної адреси без згоди власника. За потреби використовуйте приблизну точку району та прямо пояснюйте це у тексті оголошення.

## Публікація на GitHub Pages

1. Створіть порожній репозиторій на GitHub і додайте його як `origin`:

   ```bash
   git remote add origin https://github.com/ВАШ_КОРИСТУВАЧ/rentora-ua.git
   git push -u origin main
   ```

2. На GitHub відкрийте **Settings → Pages → Build and deployment → Source** і виберіть **GitHub Actions**.
3. Workflow [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) задеплоїть сайт після кожного push у `main`.
4. Дочекайтеся завершення workflow в розділі **Actions**. Адреса Pages буде в результаті job `deploy`.

## Структура

```text
.
├── data/listings.json         # єдине джерело даних оголошень
├── index.html                 # оболонка статичного SPA
├── app.js                     # routing, каталог, фільтри, карта, детальні сторінки
├── styles.css                 # адаптивні стилі
└── .github/workflows/
    └── deploy-pages.yml       # GitHub Pages deployment
```

## Перевірка перед запуском

- Перевірте структуру і звʼязки даних: `python3 scripts/validate_data.py`.
- Відкрийте домашню сторінку, каталог, одну кімнату та одну квартиру.
- Спробуйте фільтри, список/карту, стрілки каруселі, маркер карти й галерею.
- Перезавантажте кожне hash-посилання.
- Замініть `hello@example.com` у [`app.js`](app.js) на робочу контактну адресу.
- Замініть усі демонстраційні значення перед публікацією.
